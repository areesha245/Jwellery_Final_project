# Charmant - Luxury Jewelry E-Commerce Website


Charmant is a modern, elegant e-commerce website designed for a luxury jewelry brand. The website showcases premium jewelry collections with a focus on minimalist design, bridal pieces, and timeless classics.

## Features

### Core Functionality
- Responsive Navigation Bar - Fixed navbar with brand logo, shop links, contact information, and shopping cart
- Hero Section - Eye-catching banner with brand tagline and call-to-action button
- Product Collections - Three main jewelry collections:
  - Minimalist Elegance
  - Bridal Bliss
  - Timeless Classics

- Featured Products - Newest Items section displaying latest jewelry pieces in an organized grid layout
- Testimonials Section - Animated slider showcasing customer reviews with images
- Newsletter Signup - Email subscription section for marketing campaigns
-Footer - Comprehensive footer with contact info, menu links, and social media
